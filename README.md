## Project Overview

Apex Horizon 3D delivers fast, arcade-oriented racing on Android through a bright synthwave presentation. Drive along illuminated 3D highways, avoid traffic that is generated dynamically, and deploy nitro when you need an extra burst of speed.

The project combines Kotlin, Jetpack Compose, Three.js, and WebGL across its interface and game presentation. Instead of aiming for realistic simulation, it focuses on short, energetic driving sessions supported by neon scenery and a frosted glass HUD.
